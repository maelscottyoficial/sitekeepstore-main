# Project Summary
The project is a web application for managing customer orders within an e-commerce platform. It allows users to view purchase history, track order statuses, and manage purchases efficiently. The application leverages Atoms Cloud for secure data storage, enhancing user experience with features like a custom login modal and an admin panel for comprehensive product and order management. Recent updates include a settings page for integrating Mercado Pago payment processing and a fully responsive admin panel.

# Project Module Description
The project consists of several functional modules:
- **Backend**: Manages order processing, user authentication, and database interactions.
- **Frontend**: Provides the user interface for order tracking and admin functionalities, now fully responsive.
- **APIs**: Facilitates communication between frontend and backend services.

# File Description Inventory
- **app/backend/**: Contains server-side code for handling requests and managing data.
- **app/frontend/**: Contains client-side code for rendering the user interface and handling user interactions.
- **assets/**: Stores images and other media used in the application.
- **app/frontend/src/components/Header.tsx**: Includes a link to the admin panel.
- **app/frontend/src/components/LoginModal.tsx**: Modal component for user authentication.
- **app/frontend/src/components/AdminLayout.tsx**: Updated layout component for the admin panel with responsive design.
- **app/frontend/src/pages/AdminProducts.tsx**: Page for product management with full CRUD functionality and responsive dialog.
- **app/frontend/src/pages/AdminOrders.tsx**: Page for managing orders, allowing status updates and viewing order details with responsive design.
- **app/frontend/src/pages/AdminSettings.tsx**: Page for configuring Mercado Pago API keys, utilizing the settings API.

# Technology Stack
- **Frontend**: React, TypeScript, Vite
- **Backend**: Python, FastAPI, Alembic for database migrations
- **Database**: Atoms Cloud for order data storage
- **Deployment**: AWS Lambda for serverless functions

# Usage
1. **Install Dependencies**:
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
   - Navigate to the backend directory and run:
     ```
     pip install -r requirements.txt
     ```

2. **Build the Project**:
   - For the frontend, run:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend server:
     ```
     python main.py
     ```
   - Start the frontend development server:
     ```
     pnpm run dev
     ```
