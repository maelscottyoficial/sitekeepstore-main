# Project Context

## Project Overview
Keep Store - Brazilian e-commerce website for electronics and tech accessories. Rebuilt with React + shadcn/ui + Tailwind CSS for better performance and elegance.

## Key Decisions
| Date | Decision | By | Rationale |
|------|----------|-----|-----------|
| 2026-05-19 | Use dark theme with blue/purple accents | Alex | Matches tech store branding, modern feel |
| 2026-05-19 | Single page app with all sections | Alex | Original site is single page, simpler MVP |
| 2026-05-19 | Use shadcn/ui components | Alex | Consistent, accessible, fast |

## Constraints
- Color Palette: Dark background (#0a0a0f), cards (#1a1a2e), accent blue (#6366f1), accent purple (#8b5cf6), text white/gray
- Typography: Inter font, bold headings, clean product text
- Layout: Full-width hero, grid-based sections, responsive
- Max 8 code files
- All product data hardcoded (no backend needed for MVP)
- Images: 4 generated (hero banner, headphones promo, speakers promo, logo)
